# 霓虹清扫者

一个适合新手继续学习和修改的 Phaser 3 像素风俯视角射击游戏。

## 直接开始

1. 双击 `index.html`。
2. 等待浏览器加载游戏。
3. 使用 `W`、`A`、`S`、`D` 移动，移动鼠标瞄准，按住鼠标左键射击。

## 操作按键

- `P`：普通关卡中暂停整个游戏，再按一次继续；最终 Boss 战中只冻结 Boss 和激光倒计时，玩家仍可移动和射击。
- `N`：跳过当前关卡并进入下一关。跳关不会获得当前关卡的强化机会；最终 Boss 战中按下会直接触发破局通关。
- `R`：失败或结局画面中重新开始游戏。

第一次打开和每次游玩时需要联网，因为 `index.html` 会从公共网络载入 Phaser 3 游戏引擎。游戏不需要安装，也不需要输入命令。

## 八个关卡

八关的敌人总数依次为：

`8、16、32、64、128、256、512、1024`

敌人每隔 `0.5` 秒出现一批，每关每批出现数量依次为：

`2、4、6、8、10、12、14、16`

玩家初始有 3 点生命，并且进入下一关时不会自动恢复生命。每个普通敌人有 3 点生命，接触玩家时会造成 1 点伤害。

## 中途小 BOSS

- 第 4 关：进入关卡后先出现“突击执行者”。它有 60 点生命，会高速追击并进行近战攻击；击败它后才开始出现普通敌人。
- 第 6 关：进入关卡后先出现“弹幕控制者”。它有 100 点生命，会与玩家保持距离，每隔 0.85 秒发射一组三发扩散子弹；击败它后才开始出现普通敌人。

小 BOSS 的攻击每次造成 1 点伤害。击败小 BOSS 和当前关卡的全部普通敌人后，才算真正完成这一关。

## 永久强化

整局最多可以选择 5 次强化。通过第 1 至第 5 关后，每关都可以选择一次永久保留到后续关卡的强化：

- 攻速提升：射击间隔减少 18%。
- 并排弹道：每次射击增加 1 颗并排子弹。
- 火力强化：每颗子弹的伤害增加 1 点。
- 生命强化：当前生命和生命上限同时增加 1 点。

生命强化属于升级效果，不是关卡回血；没有选择生命强化时，进入下一关仍然不会恢复生命。通过第 5 关并完成第五次强化后，后续关卡不再出现强化选择。第 8 关结束后进入隐藏结局。

## 项目结构

- `index.html`：游戏入口，双击打开这个文件。
- `src/main.js`：关卡、战斗、强化和结局逻辑。
- `src/styles.css`：浏览器页面外观。
- `README.md`：这份使用说明。

## 可选的开发方式

项目保留了 Vite 配置。如果以后需要在 VS Code 中开发，可以在终端运行：

```powershell
npm.cmd run dev
```
